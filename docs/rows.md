# Rows

A row is one record in the table.

## Create, edit, copy, and delete

- Click **Create row** above the table, fill in the columns, and save. On a small screen the same action is the plus button.
- Click a cell to edit it inline when you have permission to update rows.
- Open the row menu and choose **Edit row** to edit the whole row.
- **Copy row** duplicates the row when you have permission to create rows.
- **Delete row** removes it when you have permission to delete rows.

Mandatory columns must have a value before the row can be saved.

## Search

Use the **Search** field next to **Create row**. The search looks through the visible cells and highlights matches.

## Metadata columns

A table or view can also show columns that Tables fills in for you:

- **ID**
- **Creator**
- **Last editor**
- **Created at**
- **Last edited at**

These appear in CSV export when they are visible.
