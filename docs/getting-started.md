# Getting started

Open **Tables** from the app menu. The left sidebar lists **Favorites**, **Tables**, and **Applications**. Use **Filter items** at the top of the sidebar to narrow that list.

Tables is built for day-to-day lists and team data. Very large tables, on the order of thousands of rows, can be slow to load.

## Create a table

1. Next to **Tables**, click **Create table**.
2. Enter a **Title**. The title is required and can be at most 200 characters.
3. Optionally enter a **Description** and choose an emoji with **Select emoji**.
4. Choose how to start:
   - **Custom table** creates an empty table.
   - **Import table** creates the table and then opens the import dialog. See [Import and export](import-export.md).
   - **Import Scheme** creates the table from a previously exported scheme file.
   - A template fills in columns, and in some cases sample rows.
5. Click **Create table**.

You can change the title, description, emoji, and column order later. Open the table menu and choose **Table settings**.

## Templates

These templates are available in the create dialog:

| Template | What it sets up |
| --- | --- |
| ToDo list | A simple task list |
| Members | People and a few basic attributes |
| Customers | A customer list |
| Vacation requests | Requests you can collect and manage |
| Weight tracking | Weight and related health measures |

Selecting a template fills the title with the template name. You can edit that title before you click **Create table**.

## Favorites and archive

Open the table menu in the sidebar:

- **Add to favorites** pins the table under **Favorites**. **Remove from favorites** takes it off that list.
- **Archive table** moves it under **Archived tables**. **Unarchive table** brings it back.

A table that is a favorite is not offered for archive, and an archived table is not offered as a favorite.
